# 案場電表判讀與控制批次測試指南

建立日期：2026/08/17（← 0817 新增）

## 一、用途

整理全興案場電表判讀、契約容量、儲能限制及控制批次測試方式。未經正式手冊或現場確認的項目均標示為「待確認」。

## 二、電表畫面判讀

| 項目 | 判讀位置／方向 | 注意事項 |
|---|---|---|
| 總功率 | `功率 → 實時值 → 總量` | 記錄正負方向與 kW／MW 單位。 |
| 線電壓 | 查看三相線電壓 | 三個線電壓通常應分相核對，不應直接相加；以電表手冊為準。 |
| 電流 | 查看三相電流與總覽 | 需補上現場實際畫面位置。 |
| 功率因素 | 畫面最下方總量 | 同時留意正負號與系統定義。 |
| Import | 正向電能，台電端送入場內 | 核對倍率與 kWh／MWh。 |
| Export／Output | 反向電能，場內送往台電端 | 無累積值代表目前未觀察到逆送紀錄，仍需核對電表方向設定。 |

單位換算：`1 MW = 1000 kW`、`1 MWh = 1000 kWh`。抄表時不可只記數字，必須連同倍率與單位一起記錄。

## 三、三相電流與保護值

三相系統估算公式：

```text
P = √3 × V × I × PF
I = P ÷ (√3 × V × PF)
```

若暫以 `P=6525 kW`、`V=22.8 kV`、`PF=1` 估算：

```text
I ≈ 6525 ÷ 22.8 ÷ 1.732 ≈ 165 A
```

現場另有保護電驛最大電流 `298 A` 的口述值：

```text
298 × 80% = 238.4 A
```

兩者不可直接視為同一個限制值。需確認：

- `6525` 是實功率、視在功率或畫面門檻。
- 線電壓是否確為 `22.8 kV`。
- 計算採用的功率因素。
- CT 比、電表倍率及一次側／二次側單位。
- `298 A` 是設備額定、保護 Pickup，或其他保護段設定。

## 四、契約容量與首頁門檻

| 時段 | 目前案場畫面值 | 說明 |
|---|---:|---|
| 一般時間 | `4350` | 正式契約容量。 |
| 離峰時間 | `6525` | `4350 × 1.5` 的時段門檻。 |
| 週六半尖峰 | `6525` | 依案場目前邏輯套用 1.5 倍。 |

- 契約容量 `4350` 本身沒有變動，變動的是首頁依時段顯示的參考門檻。
- 週六半尖峰不一定是假日，不可只用「是否假日」判斷。
- 最終仍需核對台電契約、系統電價設定及前端計算程式。

## 六、控制測試共同前置條件

測試前至少確認：

- 現場已同意測試時段、功率及可接受 SOC。
- PCS／BMS／VCB 沒有未解除告警。
- 電表 Import／Export 方向正確。
- 只有一個控制模式可寫入 PCS，避免不同 Job 搶控制權。
- 已設定停止條件，並知道如何將 PCS 功率歸零。
- 已建立測試紀錄，包含設定值、實際值、告警與復原結果。

建議順序：

1. 保護邏輯。
2. 抑低用電。
3. 超約控制。
4. 排程充放電。
5. 全充／全放與校正。

## 七、各批次測試重點

### 1. 抑低用電

- 門檻過低可能造成 PCS 過度放電，甚至出現逆送電風險。
- 測試值應高於現場安全下限，並先確認逆送保護。
- 目前測試排程於每分鐘 `0、10、20、30、40、50` 秒觸發。
- 預期狀態：`抑低開啟 → 待命 → 抑低保護`。
- 觀察：主電表功率、PCS 設定／實際功率、SOC、`working_status`、告警。

### 2. 超約控制

- 可使用暫時的測試契約容量，使門檻接近台電側收電值。
- 若使用 `350` 測試，必須先確認單位與現場允許範圍。
- 觀察 15 分鐘需量、PCS 是否放電及是否解除超約。
- 測試後恢復正式契約容量設定。

### 3. 排程充放電

- 先關閉抑低、超約或其他可能控制 PCS 的模式。
- 與現場確認時段、充放電方向、功率及目標 SOC。
- 建立下午放電排程後，觀察模式、PCS 功率、SOC 與排程結束復原。

### 4. 全充／全放與校正

- 本案場目前使用 `5%～95%` 的可用 SOC 範圍，保留 SOC 為 `5%`。
- 舊的 `10%～90%` 範圍則對應 `10%` 保留 SOC。
- 全充／全放屬高風險測試，需先確認 BMS 限制、溫度、告警及中止條件。
- 第二階段需觀察校正是否啟動、是否校正到預期值及結束後是否歸零。

## 八、PCS 排風扇訊號

| 訊號 | 目前定義 | 驗證方式 |
|---|---|---|
| `pcs_1_off` | 停止 | 與 PCS 實際停止狀態比對。 |
| `pcs_1_on` | 開機命令／狀態 | 下開機後確認 Relay 是否真的作動。 |
| `pcs_1_run` | 運轉 | 與風扇實際運轉比對。 |
| `pcs_1_trip` | 跳脫 | 模擬前先確認安全與復原方式。 |

## 九、測試紀錄表

| 欄位 | 紀錄內容 |
|---|---|
| 測試項目 | 保護／抑低／超約／排程／全充全放 |
| 前置狀態 | 工作模式、PCS、SOC、電表、告警 |
| 設定值 | 容量、功率、目標 SOC、開始／結束時間 |
| 實際值 | 主電表、PCS 設定與實際功率、SOC |
| 觸發結果 | 是否進入預期模式、觸發時間 |
| 異常 | 告警、逆送、設備未作動或通訊問題 |
| 復原 | PCS 歸零、模式恢復、設定值復原 |
| 結論 | 通過／失敗／待確認 |
